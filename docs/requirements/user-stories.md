# PMA User Stories

## Ziel
- Diese Datei sammelt die zentralen User Stories des MVP in einer kompakten, abgabefreundlichen Form.
- Die Stories verdichten das Product Backlog und die Sprint-Planungen.

## Account und Einstieg
- Als neuer Nutzer will ich mich registrieren koennen, damit ich PMA erstmals verwenden kann.
- Als registrierter Nutzer will ich mich einloggen koennen, damit ich auf mein Profil und meine Matches zugreifen kann.

## Profil
- Als Nutzer will ich mein Profil mit Bio, Interessen, Sprachen und Bildern pflegen koennen, damit andere mich besser einschaetzen koennen.
- Als Nutzer will ich andere Profile aufrufen koennen, damit ich vor einem Match oder Chat mehr Kontext habe.

## Discovery
- Als Nutzer will ich Menschen swipen koennen, damit ich passende Kontakte finde.
- Als Nutzer will ich auch Hobbys swipen koennen, damit Discovery nicht nur auf Personen reduziert ist.
- Als Nutzer will ich Events swipen koennen, damit ich interessante Aktivitaeten schnell entdecke.
- Als Nutzer will ich Locations swipen koennen, damit Orte als sozialer Kontext sichtbar werden.

## Match und Interaktion
- Als Nutzer will ich bei gegenseitigem Interesse ein Match erhalten, damit beide Seiten weiter interagieren koennen.
- Als Match will ich chatten koennen, damit aus einem Match eine echte Unterhaltung wird.

## Events und Karte
- Als Nutzer will ich Events erstellen, bearbeiten und filtern koennen, damit Treffen organisiert werden koennen.
- Als Nutzer will ich Event-Positionen auf einer Karte sehen koennen, damit ich Orte leichter einordnen kann.

## Priorisierung
- Muss:
  Registrierung/Login, Profil, People Swipe, Match, Chat, Event-Liste, Kartenansicht.
- Soll:
  Swipe-Decks fuer Hobbys, Events und Locations als sichtbare Erweiterung der Discovery-Idee.
- Kann:
  Tiefere Empfehlungslogik, Live-Chat und echter Datei-Upload in spaeteren Iterationen.
